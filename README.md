# Direct-Torque-Control-Method
MATLAB/Simulink implementation and analysis of Direct Torque Control (DTC) for electric motor drives.

## Project Scope:

This project focuses on the implementation and simulation of Direct Torque
Control (DTC) for an induction motor.

The project covers:

- Conventional six-sector DTC
- Improved twelve-sector DTC
- Stator flux estimation
- Electromagnetic torque estimation
- PI speed control
- Hysteresis-based torque and flux control
- Takahashi switching table
- MATLAB/Simulink simulation
- dSPACE 1104 implementation
- Experimental evaluation

The main objective is to investigate the behavior of the induction motor
under different speed and load conditions and to evaluate the effect of
the twelve-sector switching strategy on torque and flux ripples.
